Tentang Saya 📖

Siapakah Saya?

Saya merupakan pembangun web frontend yang serba boleh dan pencinta seni UI/UX digital. Saya suka memikirkan bagaimana sebuah antaramuka pengguna boleh kelihatan menarik dan berinteraksi secara semulajadi dengan manusia.

Saya sentiasa mementingkan kekemasan kod, standard kebolehgunaan (accessibility), serta keunikan visual tersendiri untuk mengelakkan reka bentuk yang terlalu standard atau membosankan.

Falsafah Reka Bentuk

"Teknologi yang baik adalah teknologi yang mudah didekati dan terasa manusiawi."

Sebab itulah saya menyukai konsep kreatif seperti *Hand-Drawn aesthetic* ini—kerana ia meraikan ketidaksempurnaan semula jadi dan membuatkan pengguna merasa lebih dekat dengan aplikasi digital.

Perjalanan Pembangunan

Saya aktif membina dan menyenggara pelbagai sistem berasaskan web bermula daripada rangka HTML asas hinggalah kepada aplikasi pentadbiran (admin dashboards) yang berprestasi tinggi.

Antara pengalaman saya termasuklah:

  • Pembangunan Modul Tempahan & Jadual
  • Sistem Inventori Peralatan Sukan
  • Modul Pengurusan Peranan & Sekuriti
  • Hab Notifikasi Masa Nyata & Laporan

Sistem Pengurusan Inventori

Aplikasi memantau kemasukan inventori perkakasan sukan secara dinamik. Pengguna boleh menyemak baki stok, memohon pinjaman barang, manakala admin boleh meluluskan dan mencetak resit penyerahan PDF.

TailwindCSS PHP Session Receipt Generator Print Module

Hab Notifikasi & Laporan Global

Sistem pengurusan mesej makluman dan laporan aktiviti. Mempunyai kebolehan untuk mengosongkan notifikasi (Clear All) sekali klik merentasi semua modul panel pengguna dan admin tanpa pertindihan menu.

JavaScript ES6 CSS Overflow UI JSON API Notification Stack
